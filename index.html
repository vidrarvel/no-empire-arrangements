Arrangement Editor

Drag across empty cells to add a block. Click a block to cycle Live -> Rec -> Loop. Double-click a block to rename it, double-click a row label to rename the row, double-click a section header to edit its bars/energy/chords/tempo. Drag a block's edge to resize, hover a block for a copy-to-section button. Use the arrows on row labels / section headers to reorder them. Ctrl+Z / Ctrl+Shift+Z (or the toolbar buttons) to undo/redo. Or just type below. No Empire.
Text syntax (optional — the grid above works without it) 
title: SONG NAME
time: 4/4
tempo: 93

section: NAME | bars | energy(0-10) | chords(optional) | tempo(optional, overrides the song tempo for this section)
row: ROW_ID | sublabel(optional)
block: ROW_ID | FROM_SECTION | TO_SECTION | state | label | sublabel(optional)

state is one of:
  live  — actively playing (default if omitted)
  rec   — capturing a loop right now
  loop  — sustaining / playing back automatically

note: free text      (shown in a Notes panel)
idea: free text      (shown in an Ideas panel)
# a comment line, ignored
Raw text source (advanced — edit directly, or paste a whole song in)
