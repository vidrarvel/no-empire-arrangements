Arrangement Editor

Drag across empty cells to add a block. Click a block to cycle Live -> Rec -> Loop. Double-click a block to rename it, double-click a row label to rename the row. Drag a block's edge to resize. Or just type below. No Empire.
Text syntax (optional — the grid above works without it) 
title: SONG NAME
time: 4/4
tempo: 93

section: NAME | bars | energy(0-10) | chords(optional)
row: ROW_ID | sublabel(optional)
block: ROW_ID | FROM_SECTION | TO_SECTION | state | label | sublabel(optional)

state is one of:
  live  — actively playing (default if omitted)
  rec   — capturing a loop right now
  loop  — sustaining / playing back automatically

note: free text      (shown in a Notes panel)
idea: free text      (shown in an Ideas panel)
# a comment line, ignored
